# Intro
## Name
ZTV International
## Discription
ZTV International is a video sharing platform inspired by YouTube, providing users with a space to upload, share, and discover various video contents.
## Users
Users who want to upload videos, watch videos, and engage with video content.
# Main features
## Video browsing
* Display video thumbnails and basic information
* Support video search and filtering
## Video playing
* Play videos in browser
* Support playback control (play, pause and seek)
## Video uploading
* Allow users to upload video files
* Fill in video metadata (title, description, tags)
## The interaction between the user
* View video comments
* Post comments under videos
## The membership
* Display membership options on the homepage: $7 per month, $72 per year
* Membership features and benefits description
# The structure of the pages
## Home page
* Display recommended videos
* Search bar for video search
* Video category navigation
* Display membership subscription options
## Video player page
* Video player
* Video information (title, description, views, upload time)
* Comment section
## Uplaod page
* Video upload form
* Metadata input fields
# Language Settings
All text content, interface labels, and user interactions on the site will be in English.
